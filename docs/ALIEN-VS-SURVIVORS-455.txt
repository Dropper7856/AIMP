Correction
- The victim is held on the selected target record from just before
  EnterPair until the action clears, and released at once if entry is
  refused. Coordinator/Prepass return while PairSourceBusy on every thread,
  so the retail brain cannot start a second kill during the pair.
- Client attack receipts release the pilot after 6s if the replayed pair
  never reaches the local Alien (previously 30s).
