Static findings
- The retail condition ConditionHasMeleeAttackAvailableOrIsAttacking
  (vtable 012E6488, test 006EFB20) is true if Alien cycle+30 bit 4
  (attacking) is set, else (*(+34B4))->vt[7](type) = byte manager+8+type
  (006D5BC0). ActionMeleeAttack start needs type 5 for an Alien:
  manager+0xD.
- These bytes are recomputed each brain update (00710D10): 006FBA40 must
  pass (target record held, DAT_016F0C8C, FUN_0077A300 false, Alien cycle
  not 0x12 without flags, and NOT (alien+2B4 == 0 && victim+2B4 != 0)), then
  006F3A30. Next, 006D5C60 sets +8+type for definitions with flags 2|4, and +D.
