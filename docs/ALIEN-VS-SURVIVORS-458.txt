457 test (042636 Host/victim, 062633 Client Alien pilot)
- Two attacks armed (stage 13, Alien cycle 1). Both ran the full 5s window and
  ended with stage 14 (window expired). Re-queries refused (stage 17). No
  epoch revoke this time (the 8s protocol limit works). The retail brain never
  started ActionMeleeAttack.

Cause (retail alien_behave.bml, dumped with CathodeLib from the Steam BML)
- SEL_1 reaches ActionMeleeAttack only through:
  ConditionLogicCharacterFlags SHOULD_ATTACK:5 -> ATTACK_CORE_BRANCH ->
  ConditionHasMeleeAttackAvailableOrIsAttacking ANY -> ActionMeleeAttack ANY,
  then ActionSetLogicCharacterFlags SHOULD_ATTACK=False.
- SHOULD_ATTACK is raised by the retail perception branches (Hit And Run,
  AGRESSIVE <=1.7m...). A player-piloted Alien never goes through them, so
  holding the target alone never starts a melee. The donor gets around this
  with its own BML gate ("Attack [MeleeAttack ANY]"), which AIMP does not
  install (native-only preview, retail BML).
- Logic character flags are bytes at AnimatedCharacter+423C+flag
  (ActionSetLogicCharacterFlags 006C8700 -> 00785B10 thiscall(character,
  flag, value), RET 8; vtable 012B8D50).
- ActionMeleeAttack start 00717D90 reads the target via
  AnimatedCharacter+34A8 -> +10 (+42C victim, +430 birth), and for an Alien
  also needs (*(+34B4))->vt[7](5) and DAT_016F0C8C.

Correction (Host, armed window only)
- Every poll: raise SHOULD_ATTACK, hold the victim on the attack-manager
  record and on the +34A8 brain record (if different). The branch clears the
  flag after each try; a cleared flag is counted (flagConsumed), proving the
  branch ran.
- Our periodic re-query is removed: the branch runs its own availability
  query, and ours would re-arm its cover ray.
- Release restores both records and clears SHOULD_ATTACK.
- alien_attack_progress adds armedPolls, flagConsumed, retargets and
  brainMissing (stage 18 brain target unavailable, 19 flag consumed).

Validation
- Four native tests pass. API 0.8.4.458 delivered locally and to
  DESKTOP-2JNROA0, SHA-256 equal. Friend patch dist/AIMP-API-patch-v458.zip.
- Not observed in game. If no kill: flagConsumed=0 means the BT never
  reached the attack branch (a higher SEL_1 branch wins); flagConsumed>0 with
  no cycle 78 means ActionMeleeAttack or its availability check refused.
